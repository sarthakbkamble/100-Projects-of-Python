# 🛠 Project: Web Foundation - Introduction to CSS

Focus: CSS Integration Methods, Selectors Hierarchy, & Color Vocabulary Styling.

🎨 Cascading Style Sheets Engine
A web design implementation project exploring the mechanics of styling web documents through inline, internal, and external CSS methods alongside element selectors and visual presentation properties.

Multi-Method CSS Integration: Demonstrates stylesheet linking techniques by implementing inline style attributes, internal <style> tags, and external .css stylesheets linked via <link> tags.

Element & Class Selectors: Targets DOM nodes using HTML element selectors and specific class references to apply custom visual properties uniformly across markup structures.

Color Vocabulary Application: Applies named colors, RGB, and hexadecimal color codes across font properties and background containers to build a structured visual color palette project.

Separation of Presentation: Decouples raw HTML structure from design declaration rules, maintaining clean document markup while delegating layout presentation to dedicated external CSS files.
