# 🛠 Project: Web Scraping with BeautifulSoup

**Focus:** Web Scraping, HTML Parsing, Data Extraction, & File Handling.

## 🎬 100 Movies You Must Watch

A Python web scraping project that uses `Requests` and `BeautifulSoup` to extract a list of the 100 greatest movies from an archived Empire Online webpage and save the results into a text file.

* **🌐 Web Scraping:** Uses the `requests` library to send an HTTP request and retrieve the webpage content from the Internet Archive.

* **🔍 HTML Parsing:** Uses `BeautifulSoup` to parse the HTML document and locate movie titles based on their HTML tags and CSS classes.

* **📊 Data Extraction & Processing:** Extracts the movie titles, reverses their order to restore the intended ranking, and processes the results into a clean list.

* **📄 File Handling:** Writes the extracted movie titles line-by-line into a `movies.txt` file for easy access and further use.

* **🐍 Python Libraries:** Demonstrates practical use of `requests` and `BeautifulSoup` for retrieving and processing structured information from web pages.

Building web scraping projects provides a practical foundation for understanding HTTP requests, HTML structure, data extraction, and automated information collection.
